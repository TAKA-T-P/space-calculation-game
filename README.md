# スペース計算ラリー v2.2

襲来するUFOを計算の力で撃退する、ブラウザで遊べる計算練習ゲームです。
小学1年生から中学1年生までの範囲をカバーする **35種類** の計算モードを収録しています。

> 計算の力で地球を守れ！

v2.1 では、塾・学校の集団授業でクラス全員が同じ条件で取り組める **「授業内大会」** モードを追加しました。
v2.2 では、授業内大会の結果を自動で集めて先生の画面でランキング発表できる **「オンライン集計」** を追加しました（[詳しくはこちら](#オンライン集計v22)）。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（インストール・ビルド不要）。
画像・BGMファイルは `index.html` と同じフォルダに置いてください。

### ゲームモード

| モード | 内容 |
| --- | --- |
| **UFOバトル** | 難しさ・計算の種類・UFOの速さを選んでスタート。UFOに表示された問題の正しい答えを選び、**60秒間** 地球を守り抜けばクリア。**3回間違うとゲームオーバー**。 |
| **３分集中** | 3分間で何問解けるかに挑戦。ゲームオーバーはなく、思いっきり計算練習ができます。 |
| **授業内大会** | 先生が発行したQRコードから参加し、クラス全員が同じ条件で計算に挑戦。ゲームオーバーはなく、指定時間いっぱいプレイできます（[詳しくはこちら](#授業内大会v21)）。 |

### ゲームの流れ（UFOバトル）

1. タイトル画面で「UFOバトル」を選ぶ
2. 難しさ（**ノーマル** / **ハイパー**）と計算の種類を選ぶ
3. UFOの速さを選ぶ：超低速 / おそい / ふつう / はやい / 超高速
4. カウントダウン後にゲーム開始。選択肢から正しい答えを選んでUFOを撃破

結果画面からは「リトライ」「速度変更」「ホーム」を選べます。

## 授業内大会（v2.1）

先生が計算の種類・難しさ・制限時間などを決めてQRコードを発行し、生徒がスマートフォンやタブレットで読み取って参加するモードです。
「３分集中」と同じルールで動くため、**UFOは動かず、間違えても減点だけ**。何回間違えてもゲームオーバーにならず、全員が同じ時間だけ計算練習に取り組めます。

### 先生向け：授業での使い方

1. タイトル画面の **「授業内大会」→「大会を作る（先生用）」** を選ぶ
2. 条件を設定する

   | 項目 | 選択肢 | 初期値 |
   | --- | --- | --- |
   | チャレンジ名 | 自由入力（30文字まで） | 計算ラリー大会 |
   | 計算の種類 | 35種類（カテゴリ別・推奨学年つき） | たし算 |
   | 難しさ | ノーマル / ハイパー | ノーマル |
   | 制限時間 | 1分 / 2分 / 3分 / 5分 | 3分 |
   | 出題方式 | ランダム / 全員共通問題 | ランダム |
   | 挑戦回数 | 1回 / 何度でも | 1回 |
   | 結果の集計方法 | オフライン集計 / オンライン集計（v2.2） | オフライン集計 |

3. **「QRコードを発行」** を押す
4. **「QRコードを全画面表示」** でプロジェクターや電子黒板に映し、生徒に読み取ってもらう（QRコードの下に **参加番号**（10けた）も表示されます）
5. 全員が「準備完了！」画面になったら、**「3、2、1、スタート！」** と声をかける（生徒が各自「チャレンジスタート！」を押します）
6. 時間が終わったら、生徒が結果画面（スコア・正解数）を見せるか口頭で報告し、上位者を発表する

QRコード画面ではほかに次の操作ができます。

- **URLをコピー**：チャットや学習アプリで参加URLを配布するとき
- **QRコードを画像保存**：チャレンジ名・参加番号入りのPNG画像を保存。印刷して配布するとき
- **設定に戻る** / **新しいチャレンジを作成**

#### 参加番号

QRコードと一緒に表示される10けたの数字（例：`274-837-4583`）です。QRコードを読み取れない生徒は、この番号を入力すれば同じ条件のチャレンジに参加できます。

- 計算の種類・難しさ・制限時間・出題方式・挑戦回数は番号に含まれます。番号から参加しても、QRコードから参加した生徒と同じチャレンジとして扱われ、全員共通問題なら同じ問題が出ます。
- **チャレンジ名は番号に含められません。** 番号から参加した生徒の画面には、チャレンジ名の代わりに「授業内大会 274-837-4583」と表示されます。
- 最後の1けたは入力ミスを見つけるための数字です。1けたの打ち間違いや、となり合う数字の入れ替えは「番号がちがいます」と表示されます。
- 「QRコードを発行」を押すたびに新しい番号になります。発行済みチャレンジから再表示した場合は同じ番号のままです。

#### 毎週の授業で使うとき

- **前回と同じ設定で作成**：最後に発行した設定を自動入力します。発行するたびに新しいチャレンジ（新しいID）になるので、同じ条件でも「11月第1週」「11月第2週」のように別々の大会として記録されます。
- **発行済みチャレンジ**：直近に発行したチャレンジのQRコードを、同じIDのまま再表示できます。授業中に画面を閉じてしまっても、同じ大会を続けられます。

#### 出題方式

| 出題方式 | 内容 | 向いている使い方 |
| --- | --- | --- |
| ランダム | 生徒ごとに違う問題が出ます | 普段の計算練習・自己ベスト更新 |
| 全員共通問題 | 同じQRコードから参加した全員に、同じ問題・同じ選択肢が同じ順番で出ます（間違えても順番は変わりません） | ランキング大会 |

#### 挑戦回数

- **1回**：同じ端末・ブラウザでは同じチャレンジに再挑戦できません。
- **何度でも**：結果画面に「リトライ」ボタンが出ます。ランキングに「最初の記録」と「最高記録」のどちらを使うかは、先生から指示してください。

> **再挑戦許可コード**：「1回」の設定で、トラブルにより挑戦をやり直させたい生徒がいる場合は、QRコード画面の「先生用：再挑戦許可コードを表示」で4けたのコードを確認し、その生徒にだけ伝えてください。生徒が参加画面の「先生に許可をもらって再挑戦する」にコードを入力すると、もう1回挑戦できます。

### 生徒向け：参加のしかた

1. 先生が映したQRコードをスマートフォン・タブレットのカメラで読み取る（タイトル画面を通らずに参加画面が開きます）
2. ニックネーム（12文字まで）を入れて **「準備OK！」**
3. 「準備完了！先生の合図を待とう！」と出たら待機。先生の合図で **「チャレンジスタート！」**
4. 時間いっぱい、正しい答えをどんどん選ぼう
5. 結果画面の **スコア** と **正解数** を先生に報告しよう！

QRコードが読み取れないときは、タイトル画面の「授業内大会」→「大会に参加する（生徒用）」で、先生が表示した **参加番号（10けた）** を入力すれば参加できます（ハイフンはあってもなくてもOK）。

**途中でページを閉じたり再読み込みしたりした場合**：もう一度QRコードを読み取るか「授業内大会」を開くと、「続きから再開する」が表示されます。スコアや正解数は引き継がれますが、**時間は止まらずに進んでいる** ので、制限時間が最初に戻ることはありません。時間が過ぎていた場合は、その時点の結果が表示されます。

### スコアと記録

- スコアの計算は「３分集中」と同じです（基本点 1,000点 × 得点倍率 ＋ コンボボーナス、不正解は減点）。制限時間が違うチャレンジのスコアは比べられないので、ランキングは同じチャレンジの中だけで行ってください。
- 結果画面には、スコア・正解数・解答数・正答率・最大コンボが表示されます。
- 結果画面には通常プレイと同じ **称号** も表示されます。制限時間が違っても同じ基準になるよう、スコアに次の倍率をかけた値で称号を決めます（表示されるスコアは変わりません）。

  | 制限時間 | 1分 | 2分 | 3分 | 5分 |
  | --- | --- | --- | --- | --- |
  | 称号判定の倍率 | ×3 | ×1.5 | ×1 | ×0.6 |
- 授業内大会の記録は、通常モードのハイスコアとは **別に** 保存されます。TOTAL SCORE や、TOTAL SCORE で決まる称号には影響しません。
- 授業内大会で正解した問題数は、ストーリー解放用の **累計正解数には加算** されます（再開しても二重には数えません）。
- 過去の結果は **「記録」→「授業内大会」** で確認できます。同じチャレンジに複数回挑戦した場合は、各回の結果が表示されます。

### 制約（オフライン集計の場合）

- 生徒のスコアは先生の画面に自動では集まりません。結果画面を見せるか、口頭で報告してもらいます（自動で集めたい場合は [オンライン集計](#オンライン集計v22) を使います）。
- スタートは先生の端末から遠隔操作できません。先生の合図で各自がボタンを押します。
- 「1回」の制限は **同じ端末・同じブラウザの中だけ** で有効です。別の端末を使ったり、ブラウザのデータを削除したりした場合の再挑戦までは防げません。
- QRコードは公開URL（GitHub Pages など）で開いたページから発行してください。パソコン内のファイルとして開いたページで発行したQRコードでは、生徒の端末から参加できません。

## オンライン集計（v2.2）

授業内大会の作成時に **「結果の集計方法」→「オンライン集計」** を選ぶと、生徒の結果がチャレンジ終了後に自動で送信され、先生の画面で結果を取得してランキングを発表できます。
集計には Firebase（Authentication・Cloud Firestore）を使います。**初期値は「オフライン集計」** で、オフライン集計・UFOバトル・３分集中は Firebase に一切接続しません（Firebase が使えない状態でも、これまでどおり遊べます）。

### 先生：オンライン大会の作成

1. 「授業内大会」→「大会を作る（先生用）」で、条件を設定して **「オンライン集計」** を選ぶ
2. **「Googleアカウントでログイン」** から、KEC職員用Googleアカウント（`@kec.gr.jp`）でログインする
   - それ以外のアカウントでは「オンライン大会の作成・管理は、KEC職員用Googleアカウントでログインしてください。」と表示され、作成できません（オフライン集計は使えます）
3. 挑戦回数が「何度でも」のときは、**ランキングに採用する記録**（最高記録／最初の記録、初期値：最高記録）を選ぶ。「1回」のときは最初に完了した記録を採用します
4. **「QRコードを発行」** を押すと、オンライン大会が登録され、QRコードと参加番号が表示されます（「オンライン集計：ON」と表示）

QRコード・参加番号・全員共通問題・挑戦回数・再挑戦許可コード・中断と再開など、授業内大会の機能はオフライン集計と同じように使えます。集計方法も「前回と同じ設定で作成」に保存されます。

### 生徒：参加と結果の送信

- QRコード・参加番号のどちらからでも参加できます。アカウント登録やメールアドレスの入力は不要です（匿名認証を使います）
- 参加画面に「オンライン集計：ON」「チャレンジ終了後、結果が先生に自動送信されます。」と表示されます
- **ゲーム中は通信しません。** 問題・採点・タイマーなどはすべて端末内で動くので、途中で通信が切れてもプレイは止まりません
- 制限時間が終わると結果が1回だけ送信され、結果画面に「送信中…」→「送信完了！」と表示されます
- 送信できなかった場合は「送信できませんでした」と表示され、**「再送信する」** ボタンで送り直せます。結果は端末にも保存されているので失われません（「記録」→「授業内大会」からも再送信できます）
- 同じ結果を何度送信しても、登録されるのは1件だけです（結果IDはプレイ開始時に決まります）
- 参加番号を入力したときに通信できなかった場合は、同じ条件のチャレンジとして参加できますが、結果は自動送信されません（画面に案内が出ます。先生にスコアを報告してください）

### 先生：結果の取得とランキング発表

1. 「授業内大会」→ **「オンライン大会を管理する（先生用）」**（またはQRコード画面の「この大会を管理する」）
2. 大会一覧から大会を選ぶ（チャレンジ名・作成日時・計算の種類・難しさ・制限時間・受付状況・結果登録数を表示）
3. **「結果を取得」** を押す（その時点の結果をまとめて取得します。自動更新はしないので、あとから送信された結果を反映するにはもう一度押してください）
4. 発表方法を選ぶ

| 発表方法 | 内容 |
| --- | --- |
| TOP3特別演出 | 3位 → 2位 → 1位の順に発表。1位は暗転・カウントダウン・光の演出のあと「CHAMPION!」とニックネーム・スコアを大きく表示 |
| カウントダウン発表 | 指定した順位（例：10位）から1位まで、下位から順に発表 |
| 一括表示 | 全順位を一覧で表示 |

発表画面の操作：**次の順位**（→キー・スペースキーでも可）／**前へ**（←キー）／**スキップ**（最後まで飛ばす）／**全順位を表示**／**全画面**／**発表終了**

- 順位はスコアの高い順。同点は同じ順位です（例：1位、1位、3位）
- 同じ生徒（同じ端末）が複数回挑戦した場合も、ランキングは1人1枠です
- 結果一覧（先生用）は、プロジェクターに映してもネタバレしないよう、最初は非表示です。同じニックネームの生徒がいる場合は、IDの末尾で見分けられます
- **「受付を終了」** を押すと、それ以降の結果は登録されません（ゲーム中の生徒がいないことを確認してから押してください）
- 大会の保存期限は作成から **90日** です。期限を過ぎた大会には結果を送信できません。不要になった大会は管理画面の **「この大会と結果を削除する」** で削除してください

### オンライン集計の注意点

- 先生権限は「Googleでログイン・メールアドレス確認済み・`@kec.gr.jp`」で判定しています。ドメインだけでは在籍状況までは保証できないため、将来は承認済みUIDによる管理に切り替えられるようにしてあります（`firestore.rules` の `isTeacher()`）
- 「1回」の制限は端末ごとです。ブラウザのデータを消したり別の端末を使ったりすると再挑戦できます。この場合は別の生徒として登録されるので、管理画面の結果一覧で確認してください
- スコアは生徒の端末で計算して送信するため、改ざんを完全には防げません（サーバー側ではスコアの範囲・正解数と解答数の整合性などを確認しています）
- 期限切れの大会は自動では削除されません（無料プランで追加料金が発生しないよう、先生が手動で削除する方式です）

### Firebase の設定（管理者向け）

オンライン集計を使うには、Firebaseプロジェクト `space-calculation-game` で次の設定が必要です。

1. **Authentication → Sign-in method** で「Google」と「匿名」を有効にする
2. **Authentication → 設定 → 承認済みドメイン** に `taka-t-p.github.io` を追加する
3. **Firestore Database** を作成する（本番環境モード。リージョンは `asia-northeast1`（東京）などを推奨）
4. **Firestore Database → ルール** に、このリポジトリの [`firestore.rules`](firestore.rules) の内容を貼り付けて公開する
   （Firebase CLI を使う場合は `firebase deploy --only firestore:rules`）
5. **プロジェクトの設定 → マイアプリ（ウェブアプリ）** の設定値を [`firebase-config.js`](firebase-config.js) に貼り付けて、GitHub にプッシュする

`firebase-config.js` の値（apiKey など）は、Webページに公開される前提の識別情報で秘密ではありません。データの保護はセキュリティルールで行っています。**管理者用の秘密鍵（サービスアカウントの JSON）は絶対にリポジトリに置かないでください。**
`apiKey` と `appId` が空のあいだは、オンライン集計は選べても大会を作成できません（オフライン集計はそのまま使えます）。

#### Firestore のデータ構成

| パス | 内容 | 読み書きできる人 |
| --- | --- | --- |
| `classChallenges/{大会ID}` | 大会情報（チャレンジ名・条件・参加番号・作成者UID・受付状況・ランキング採用方式・作成日時・保存期限） | 作成：先生／取得：参加者（1件ずつ）／一覧・受付終了・削除：作成した先生 |
| `classChallenges/{大会ID}/results/{結果ID}` | 生徒の結果（匿名UID・ニックネーム・スコア・正解数・解答数・正答率・最大コンボ・挑戦番号・開始/終了時刻） | 登録：生徒本人（変更不可）／確認：本人と作成した先生／一覧・削除：作成した先生 |
| `joinCodes/{参加番号}` | 参加番号 → 大会ID の対応表 | 作成・削除：先生／取得：参加者 |

参加番号には、オンライン大会かオフラインかの区別も含まれています。オフラインの番号を入力したときは通信しません。オンライン大会の番号は、受付中の大会と重複しないことを確認してから発行します（期限切れの番号は再利用できます）。

#### Firebase SDK の更新（開発者向け）

Firebase SDK は CDN を使わず、`lib/firebase-sdk.js` に必要な機能だけをまとめて同梱しています（オンライン集計を使うときだけ読み込みます）。更新する場合は次のコマンドで作り直します。

```
cd tools/firebase-sdk
npm install
npm run build
```

## 計算の種類（35種類）

計算の種類選択画面では、推奨学年と得点倍率が表示されます。

| カテゴリ | 計算の種類 |
| --- | --- |
| 基本の四則演算 | たし算 / ひき算 / かけ算 / わり算 / ミックス |
| 単位変換 | 長さの単位 / 重さの単位 / 面積の単位 / 体積の単位 / 単位MIX |
| その他 | 逆算 / 仮分数⇔帯分数 / 最小公倍数 / 最大公約数 / 小数⇔分数 |
| 小数 | 小数のたし算 / ひき算 / かけ算 / わり算 / 小数MIX |
| 分数 | 分数のたし算 / ひき算 / かけ算 / わり算 / 分数MIX |
| 割合・比・速さ | 割合（金額） / 割合の3用法 / 速さの3用法 / 比を簡単にする / 比例式 |
| 正負の数 | 加法 / 減法 / 乗法 / 除法 / 正負の数MIX |

推奨学年はおおむね **小1〜中1**（例：たし算 小1〜、分数のかけ算 小6〜、正負の数 中1〜）。
ハイパーモードでは問題が難しくなり、推奨学年が上がる種類もあります。
「単位」ボタンから単位換算の早見表を確認できます。

## スコア

- **基本点**：UFOの速さで変化（超低速 2,800 〜 超高速 3,200 点。３分集中・授業内大会は 1,000 点）
- **得点倍率**：計算の種類と難しさごとに設定（例：ノーマルのたし算 0.75倍、ハイパーの分数のひき算 3.00倍）
- **コンボボーナス**：連続正解で 1コンボあたり +10 点（上限 +300 点 / 30コンボ）
- **残機ボーナス**：クリア時に残った残機に応じて加算（計算の種類・速さで変動）

### メダル

UFOバトルを各速度でクリアすると、計算の種類ごとにメダルを獲得できます。

| 速さ | メダル |
| --- | --- |
| ふつう | 🥉 ブロンズ |
| はやい | 🥈 シルバー |
| 超高速 | 🥇 ゴールド |

### 称号

全35種類のハイスコア合計（TOTAL SCORE）に応じて、5,000点ごとに称号が上がります。
「LV.1 見習い宇宙飛行士」から始まり、最高位は 100,000点以上の「**LV.MAX 計算銀河の創造主**」です。

## ストーリー

「記録」メニューから、プロローグと全20話のストーリーを閲覧できます。
ストーリーは **累計正解数** に応じて順に解放されます（第 n 話の解放には累計 n² × 5 問の正解が必要。例：第2話 20問、第10話 500問、第20話 2,000問）。

## 記録の保存

ハイスコア・クリア情報・累計正解数・BGM設定などはブラウザの `localStorage` に保存されます（ブラウザや端末が変わると記録は引き継がれません）。
ハイスコア画面の「消去」ボタンで、ハイスコア・クリア情報・累計正解数を削除できます。授業内大会の記録や先生用の設定は「消去」では削除されません。

授業内大会のデータは、通常の記録とは別の `classChallenge_` で始まるキーに保存されます。

| キー | 内容 |
| --- | --- |
| `classChallenge_results` | 授業内大会の結果一覧（オンライン大会の結果は、大会ID・結果ID・送信状態も保存） |
| `classChallenge_active` | 進行中のチャレンジ（再読み込みからの再開用） |
| `classChallenge_teacherLast` / `classChallenge_teacherHistory` | 先生用の前回設定（集計方法・ランキング採用方式を含む）・発行済みチャレンジ |
| `classChallenge_nickname` / `classChallenge_extraAttempts` | 前回のニックネーム・再挑戦許可の状況 |

## ファイル構成

```
index.html                 ゲーム本体（HTML / CSS / JavaScript を1ファイルに収録）
lib/qrcode.js              QRコード生成ライブラリ（授業内大会用）
lib/firebase-sdk.js        Firebase SDK（オンライン集計用。使うときだけ読み込む）
firebase-config.js         Firebase Webアプリの設定値（オンライン集計用）
firestore.rules            Firestore セキュリティルール
firebase.json / .firebaserc  Firebase CLI 用の設定（ルールの公開に使用）
tools/firebase-sdk/        lib/firebase-sdk.js を作るためのビルド設定
prologue.png               プロローグ画像
STORY_01.png 〜 STORY_20.png  ストーリー画像（第1話〜第20話）
サイバー・ストーリー.mp3    タイトル画面などのBGM
スペースホッパー.mp3        ストーリー画面のBGM
ゲームクリアー.mp3          ゲームクリア時の音楽
```

GitHub Pages などの静的ホスティングで動作します。サーバーに接続するのはオンライン集計を使うときだけです（Firebase）。
QRコードの生成には [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator)（Kazuhiko Arase 作、MIT License）、オンライン集計には [Firebase JavaScript SDK](https://github.com/firebase/firebase-js-sdk)（Google、Apache License 2.0）を、どちらもCDNを使わずに同梱しています。
効果音は Web Audio API で生成しています。
PC・タブレット・スマートフォン（縦画面）に対応しています。
